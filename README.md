# LocalNotes

A native iPadOS note-taking app for Apple Pencil, built on PencilKit and SwiftUI with zero third-party dependencies. The canvas is an infinite vertical sheet of squared paper: you write with the pencil, pan and zoom with your fingers, and the app never runs out of space. Everything is stored locally in the app's Documents directory, and any note can be exported as a true vector, multi-page A4 PDF. The project builds from a single XcodeGen spec and ships as an unsigned IPA intended for sideloading with SideStore or AltStore.

- Infinite vertical canvas that grows on demand, with a 24 pt squared-paper grid that scrolls with the ink.
- Apple Pencil only for drawing (`drawingPolicy = .pencilOnly`); fingers always pan and zoom.
- Pen and vector eraser, driven by a minimal custom floating toolbar instead of `PKToolPicker`.
- Draw & Hold gesture: hold the pencil still for 0.75 s and the freehand stroke snaps to a straight line.
- Vector PDF export, multi-page A4, with no rasterisation of strokes.
- Local-only storage: one binary `.note` file plus a JSON metadata sidecar per note.
- Debounced autosave with explicit flushes on note switch, view disappearance and scene-phase changes.

## Requirements

- macOS with Xcode 15 or later (Xcode 26/27 verified) and the command line tools.
- `xcodegen` to generate the Xcode project: `brew install xcodegen`.
- An iPad on iPadOS 17.0 or later with an Apple Pencil to run the app.
- SideStore (or AltStore) and a working sideloading setup to install the IPA, since the build is unsigned for Apple provisioning.

## Architecture

### Infinite canvas

`InfiniteCanvasView` is a `PKCanvasView` subclass, and therefore a `UIScrollView`. Whenever the visible viewport comes within 1200 pt of the current bottom edge, the view adds 3000 pt to `contentSize.height`. The same check is also driven by a KVO observer on `contentOffset`, so the growth triggers whether the user is scrolling, zooming or drawing near the edge. The result is an append-only canvas: paper is added before it is needed, and writing never stops because of a fixed page height.

### Grid background

The squared paper ("quadretti") is a 24 pt grid drawn as a single cached `UIColor(patternImage:)` tile. The tile is generated once and tiled by Core Graphics, so memory stays constant no matter how tall the canvas becomes. The grid lives on a content-anchored `UIView` placed *inside* the scroll view, which makes it part of the scrollable content: the grid moves and zooms together with the ink instead of sliding underneath it. The canvas itself is `isOpaque = false` with a clear background so PencilKit's transparent drawing surface lets the grid show through; an opaque canvas would hide it entirely since PencilKit draws in its own layer above the scroll view's content.

### Pencil-only drawing policy

`drawingPolicy = .pencilOnly` restricts stroke input to the Apple Pencil. Finger touches fall through to PencilKit's built-in scroll and zoom handling, so panning and pinching never leave accidental ink. Zoom is clamped to 0.5x–4.0x. PencilKit stores strokes as vectors, so zooming within that range never pixelates handwriting.

### Draw & Hold

`PencilHoldTracker` is a pencil-only `UIGestureRecognizer` that runs simultaneously with PencilKit's own recognisers and never enters the `.recognized` state. While a stroke is in progress it measures movement: if the pencil stays within 4 pt of its reference point for 0.75 s without lifting, the tracker reports a hold. `StraightLineSnapper` then atomically replaces the in-progress freehand stroke with a straight line between its first and last sample, built from 48 interpolated `PKStrokePoint`s, preserving the original ink, transform and mask. A `UIImpactFeedbackGenerator(style: .light)` confirms the snap. The snapped stroke is re-asserted until the pencil actually lifts, so PencilKit cannot resurrect the freehand version during the remainder of the touch.

### Storage format

Each note is two files under `<Documents>/Notes/`:

- `<UUID>.note` — the native binary `PKDrawing.dataRepresentation()`.
- `<UUID>.meta.json` — a sidecar with title, timestamps and stroke count.

The sidecar exists so the document list can render titles, dates and stroke counts without decoding every drawing, which keeps list scrolling cheap. All writes are atomic. `DocumentManager` is `@MainActor`-isolated (the spec's `@globalActor` option) because `PKDrawing` is not `Sendable`; keeping every touch of drawing data on the main actor avoids data races that Swift 6 concurrency checking would otherwise flag.

### PDF export

Export is true vector output. `PDFExporter` builds a multi-page A4 document (`595.28 x 841.89` pt) with `UIGraphicsPDFRenderer` and rebuilds every stroke as a `UIBezierPath`. Strokes are never rasterised, so a note with a thousand strokes exports without producing a single bitmap; the output stays sharp at any zoom and prints correctly.

### Autosave

Edits are persisted by a 0.8 s debounce. Pending saves are flushed immediately when the user switches notes, when the editor view disappears, and on scene-phase changes (for example backgrounding the app), so no debounce window can lose work.

## Building

```sh
brew install xcodegen
xcodegen generate
./build_ipa.sh
```

`project.yml` defines a single target: `LocalNotes`, bundle identifier `com.stefano.localnotes`, `IPHONEOS_DEPLOYMENT_TARGET 17.0`, `TARGETED_DEVICE_FAMILY = 2` (iPad only), all four iPad orientations, and `SWIFT_VERSION 6.0`.

`build_ipa.sh` produces `LocalNotes.ipa` in the repository root and automatically selects one of two paths:

- **Path A (preferred)** — `xcodebuild archive` in Release for `-sdk iphoneos` with `CODE_SIGNING_ALLOWED=NO`, then packaging the resulting `Payload/` directory into a zip. This path is used whenever the Xcode license has been accepted.
- **Path B (fallback)** — when `xcodebuild` is gated (for example, the Xcode license has not been accepted yet, which requires an admin password to fix), the script falls back to Xcode's ungated toolchain binaries: `swiftc -sdk <iPhoneOS.sdk> -target arm64-apple-ios17.0 -swift-version 5 -parse-as-library` for all sources, `actool` for `Assets.xcassets`, and `plutil` to merge `CFBundleIcons` and inject `CFBundleExecutable`, `CFBundleIdentifier`, `CFBundleSupportedPlatforms`, `MinimumOSVersion` and `UIDeviceFamily`. The bundle is then ad-hoc `codesign`ed and zipped with `zip -r -9`.

The script prints which path it took, so the log is the source of truth. Accepting the license enables Path A:

```sh
sudo xcodebuild -license accept
```

To force the fallback even when `xcodebuild` is available:

```sh
LOCALNOTES_FORCE_FALLBACK=1 ./build_ipa.sh
```

The IPA is intentionally unsigned for Apple provisioning: SideStore and AltStore re-sign it with the user's Apple ID at install time.

## Installing on iPad with SideStore

1. Build the IPA on the Mac: run `./build_ipa.sh`. When it finishes, `LocalNotes.ipa` is in the repository root.
2. Get the file onto the iPad: AirDrop it, copy it to iCloud Drive and open it in the Files app, or download it from a URL (for example an IPA attached to a GitHub release).
3. Open SideStore and tap `+`, then pick the IPA in the Files picker. If the IPA is reachable by URL, use "Import from URL" instead, or pick "Open in SideStore" from the share sheet.
4. Sign in with the same Apple ID that was used for the pairing file. SideStore re-signs the app and installs it.
5. Free Apple developer accounts must refresh the app every 7 days. Keep SideStore's background refresh enabled so it can re-sign before the profile expires.

## Verification status

Verified on this machine:

- All 17 Swift source files type-check with 0 errors and 0 warnings under both `-swift-version 5` and `-swift-version 6`.
- `LocalNotes.ipa` is approximately 419 KB and passes `unzip -t` with no errors.
- The app bundle contains `LocalNotes` (Mach-O arm64, `LC_BUILD_VERSION` `platform 2` = iOS, `minos 17.0`), `Assets.car`, `Info.plist`, `PkgInfo`, the app icons and an ad-hoc `_CodeSignature`.
- `codesign --verify` passes on the packaged bundle.

Not verified:

- No on-device install or run was possible, so runtime behaviour (Pencil input, Draw & Hold, PDF output) has not been exercised on an iPad.
- Path A of `build_ipa.sh` (the `xcodebuild archive` route) was never executed: this machine had not accepted the Xcode license, so every build so far went through Path B. Path A is implemented but untested.

## Known constraints

- iPad only (`TARGETED_DEVICE_FAMILY = 2`) and iPadOS 17.0 or later.
- Side-load only: the IPA is not signed for App Store or TestFlight distribution.
- The eraser is vector-only (`.vector`), so it removes whole strokes instantly; there is no pixel eraser.
- No iCloud sync. Storage is local to the app container by design.
- Each note is two files on disk (`.note` plus `.meta.json`), so external tooling must keep them together when copying notes in or out.
